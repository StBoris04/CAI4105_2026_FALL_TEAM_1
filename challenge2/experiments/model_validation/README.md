# Model-validation experiments

This folder contains optional, training-only experiments and their saved
results. They support discussion of model stability, feature engineering,
ensemble choices, and decision thresholds.

They do not replace the final workflow. Run
[`../../models/purchase_prediction.ipynb`](../../models/purchase_prediction.ipynb)
to develop the final model and generate
`challenge2/submissions/predictions.csv`.

The validation report is in [model_validation_report.md](model_validation_report.md).
